# Food Ordering System

ASP.NET-based food ordering management system with SQL Server integration.

## 🚀 Features
- User authentication
- Food ordering
- Order management
- SQL Server integration

## 🛠 Tech Stack
- C#
- ASP.NET
- SQL Server
- T-SQL

## ⚙️ Setup
1. Clone repository
2. Restore database
3. Open solution in Visual Studio
4. Run project
